# 抖音短视频剪辑框架

这是决策框架，不是固定模板。先服从素材真实性、账号定位和目标受众。

## 开头评分（0–2 分/项）

- 具体性：观众能否立刻知道“这条与我有什么关系”。
- 画面变化：首帧是否有人、动作、结果或明显冲突。
- 信息差：是否提出一个值得继续看的问题或结果。
- 可信度：承诺是否能由后文兑现，是否避免夸大。
- 声画一致：口播、字幕和画面是否表达同一个重点。

总分低于 7 时，优先重写开头，而不是靠更多特效补救。

## 默认节奏

- 0–3 秒：结果、冲突、问题或反常识，避免自我介绍和空镜铺垫。
- 3–10 秒：交代处境与代价，迅速兑现一部分承诺。
- 中段：每个信息单元只表达一个意思；用近景、补充画面、关键词或停顿制造节奏变化。
- 结尾：完成承诺后再给自然互动问题。不要用与内容无关的强行求赞。

知识类可稍慢以保证理解；剧情、探店、变装和结果展示类可更密。不要为了“快”剪掉必要语义或呼吸。

## 取舍顺序

1. 删除重复、口头禅、等待、对焦失败和无信息动作。
2. 保留真实反应、具体细节、过程中的阻力和可验证结果。
3. B-roll 只覆盖跳剪、解释抽象概念或展示证据。
4. 音效用于强调结构变化，不要每个切点都加。
5. 字幕优先可读性；一屏一意，关键词少量强调，避开平台按钮区。

## 交付前自检

- 静音观看，前 3 秒仍能理解主题。
- 只听声音，叙事仍连贯。
- 每个镜头都回答“它为什么必须存在”。
- 标题和封面没有超出视频实际兑现的内容。
- 结尾留下具体、容易回答的问题。
